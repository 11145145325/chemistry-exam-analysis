# 教材版本、页码与链接核查

## 确定教材版本

- 以[人教社「中小学教材电子版」目录](https://jc.pep.com.cn/?filed=%E9%AB%98%E4%B8%AD&subject=%E5%8C%96%E5%AD%A6)为唯一教材基准，只取目录中的人教版高中化学课本。目录里列出的就是当前版本，按册打开对应电子本即可，不再区分往年版本。其他出版社版本和其他学科，不据以标注化学页码。
- 册次名称照目录中该册标题的写法，全文统一，首次出现时写全称，其后可用简称。版次和印次以该册版权页或人教社明确说明为据，只有审定年份时按原文标为审定年份。
- 目录或正文暂时无法加载时，可从人教社官网「教材电子版 → 高中 → 化学」重新进入。能确认是目录对应同一电子本的副本，或用户提供的对应原页，也可用于核页。版本或对应正文无法确认时，页码写「待核」，其余解析照常进行。

## 核实内容和页码

1. 在已确认的教材里查找能直接支持当前判断的定义、反应、实验、图表或例题。目录和检索摘要用于导航，页码以实际看到的相关正文为准。
2. 以书页印刷页码为主。若 PDF 的文件页序因封面、目录等与书页不同，可另注 PDF 页序供定位。扫描裁去页码时，需从同一版本的连续页面中可靠核实实际书页；只有文件页序可核实的，明确标为「PDF 文件第 N 页，印刷页码待核」。标注以所打开电子本的版权页和页脚为准。
3. 每条标注对应具体考点，给出最窄的相关页或连续页段。若题目是依据课本原理进行迁移，指明该页支持哪条原理，并展示其如何用于题设。教材中没有直接对应内容时，说明实际依据，例如题给信息或综合推导；引用其中用到的教材原理时仍标注其页码。
4. 只有目录、转述、其他版本，或可见正文未覆盖该考点时，列出已核实的册次、章节等信息，将具体页码写为「待核」，并说明欠缺的材料。

## 引用写法

`【教材】〔册次〕，〔章／节〕，第〔印刷页码〕页（〔直接支持的考点〕）。`

册次照目录标题的写法或其中文简称，全文前后一致，首次出现时写全称。同一份解析在文首说明教材版本。题内标注为纯文本。用户要求比较不同版本时，在对应位置补明版次。

## 文首电子教材入口

- 在标题和教材版本行下方保留「电子教材」，以用户指定的人教社高中化学目录为主链接。若人教社还提供稳定的单册阅读页，可在同一处列出对应册次。题内仅用纯文本标教材位置。
- 发布前打开目录及拟附的单册阅读页，确认跳转和册次。验证单册时至少打开一张正文页。只列可用的单册入口，使用稳定的目录或阅读页面，避开临时签名地址及返回 `AccessDenied` 的文件直链。目录在当前环境打不开时，保留指定目录，注明当前访问状态。导出 PDF 或 Word 时确认链接指向原定地址。

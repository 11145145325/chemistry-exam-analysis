# 教材版本、页码与链接核查

## 确定教材版本

- 使用人民教育出版社《普通高中教科书·化学》2019 年审定系列，包括必修第一、二册及选择性必修 1–3。文首统一写「人教版，2019 年审定」。需要说明具体版次或印次时，以对应册的版权页为准。
- 核页用 2019 年审定系列对应版本的原书正文。先核对出版社、书名和册次，再核对版本信息。只有检索平台的年份标签时，进一步查原书。确认其他修订版或无法核实目标版本正文时，页码写「待核」，其余解析照常进行。

## 核实内容和页码

先解题，确定设问、得出答案所需的关键判断以及它实际考查的教材知识点，再按需查[常考知识点教材索引](textbook-index.md)。只有教材版本和具体知识点都对应时，才可使用索引中已核实的印刷页码。

1. 在原书中找到直接支持该步骤的定义、规律、反应、实验或图表。能指出该页哪条内容用来判断什么，才保留引用。仅有同一章节、相同术语、同种物质或相似情境，省略该引用。目录和检索摘要用于导航，页码以核实过的正文为准。
2. 以正文页脚的印刷页码为准。若 PDF 的文件页序因封面、目录等与书页不同，可另注 PDF 页序供定位。扫描裁去页码时，需从同一版本的连续页面中可靠核实实际书页；只有文件页序可核实的，明确标为「PDF 文件第 N 页，印刷页码待核」。
3. 每条标注写出具体知识点和最窄的相关页码。迁移题可引用实际用到的教材原理，交代它用于哪一步。题干给出的数据、反应、材料和据此推得的结论，说明其题设依据。整问如只靠题设即可解决，可省略教材栏。
4. 已明确考查某一教材知识点但无法核实正文时，只写有把握的具体考点及册次、章节，将印刷页码标为「待核」。

## 引用写法

`【教材考点】〔具体知识点〕，用于〔本题关键判断〕。〔册次〕，〔章／节〕，第〔印刷页码〕页。`

前文已说明用在哪一步时，可省略「用于」部分。文首说明教材版本，册次首次用书名页上的全称，其后可用统一简称。题内标注为纯文本。

## 文首电子教材入口

- 在标题和教材版本行下方保留「电子教材」，列出已核实可用的 2019 年审定系列各册入口。题内仅用纯文本标教材位置。
- 发布前打开拟附的阅读入口和至少一张正文页，确认册次、版本与实际可读性。选用稳定的书目页或阅读页。入口暂不可用时标「入口待核」。导出 PDF 或 Word 后确认链接的跳转目标。

课本网可用于查找标为「2019版」的对应册次。核页和输出链接前，按上面的步骤核对原书及正文可读性。
